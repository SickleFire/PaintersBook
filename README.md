### Painter's Book is a 3D model interactive viewer made for artists like me.

Painter's Book can save your 3D figures or models, references and render your subject to your liking. Painter's Book is a teaching aid for artists. study different portrait lighting, anatomy and proportions.

[FEATURES]
  - set different camera angles for drawing references.
  - set different lighting colors.
  - set various lighting positions.
